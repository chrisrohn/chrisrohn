## Hi there 👋

🪩 **[Indie Discotheque](https://chrisrohn.com)** — a daily new-music discovery feed built from
Last.fm ([tt_discotheque](https://www.last.fm/user/tt_discotheque)), ListenBrainz, MusicBrainz, Bandcamp,
Deezer and music blogs. Listen, thumb up or down, and approved tracks get filed into the matching
"year Indie Discotheque" playlist on YouTube Music.
