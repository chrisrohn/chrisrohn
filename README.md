## Hi there 👋

🪩 **[Chris Rohn's New Music](https://chrisrohn.com)** — a daily new-music discovery feed for the
Indie Discotheque radio station, built from Last.fm ([tt_discotheque](https://www.last.fm/user/tt_discotheque)),
ListenBrainz, MusicBrainz, Bandcamp, Deezer and music blogs. Sign in with Google, thumb tracks up or down, and
approvals land in the matching "year Indie Discotheque" playlist on YouTube Music.
